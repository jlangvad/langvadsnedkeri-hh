# langvadsnedkeri-hh

Hosts the Hubhus iframe page for Langvad Møbelsnedkeri at https://hh.langvadsnedkeri.dk via GitHub Pages.

- `index.html` and `hh/index.html` are the file Hubhus sent (3 Nov 2026). Do not edit them.
- DNS: CNAME `hh` at one.com points to `jlangvad.github.io`.
- The main site langvadsnedkeri.dk runs on Squarespace, which can't serve raw files. That's why this lives here.
- Contact at Hubhus: Henrik Omdal.
